# 50th Anniversary Celebration

> A golden-jubilee tribute web page created for my grandparents' 50th wedding anniversary.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Open-2ea44f?style=for-the-badge&logo=vercel)](https://50th-anniversary-navy.vercel.app)

**Live demo:** https://50th-anniversary-navy.vercel.app

## Features
- Celebration landing page with welcome message
- Photo slideshow of family memories
- Embedded video and background music

## Tech Stack
HTML5, CSS3, JavaScript

## Project Structure
```
index.html     # the page
*.png          # slideshow images (1st.png ... )
vidio.mp4      # video
ring.mp3       # background audio
```

## Run Locally
No build step. Clone the repo and open `index.html` in a browser, or serve it:
```bash
npx serve .
```
